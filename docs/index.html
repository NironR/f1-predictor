This is how

We believe a prediction only counts when it is made before the race. Every number here comes from earlier races only, then gets scored against the simplest guess: the grid order.

Building on four public data sources

Designed to rebuild itself after every Grand Prix, with results from Jolpica, safety cars from OpenF1, laps and tyres from TracingInsights and weather from Open-Meteo in one place.

  • 213,138 laps of timing data
  • 8 core checks on every run
  • Python, pandas and scikit-learn
